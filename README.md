# KION6969

I build local-first web tools — dashboards, uptime monitors, and video editing infrastructure — that run without a database, a backend, or API keys.

## What I build

- **Self-hosted, offline-first apps** — service workers, localStorage, PWA installs, no server required
- **Developer tooling** — headless FFmpeg editing engines, MCP servers, GitHub Actions-based automation
- **Frontend** — vanilla JS, React, TypeScript; accessible, responsive, performance-conscious

## Tech I use

`JavaScript` `TypeScript` `React` `Vite` `Node.js` `FFmpeg` `GitHub Actions` `PWA` `Service Workers` `localStorage` `HTML5` `CSS3`
