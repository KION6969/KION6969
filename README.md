# KION6969

I build local-first web tools — dashboards, uptime monitors, and web applications — that run without a database, a backend, or API keys.

## What I build

- **Self-hosted, offline-first apps** — service workers, localStorage, PWA installs, no server required
- **Frontend & full-stack** — reusable React components, responsive layouts, TypeScript, and Node.js/Express backends
- **Integrations** — third-party checkout APIs, lead capture, event tracking, and deployment pipelines

## Tech I use

`HTML5` `CSS3` `JavaScript` `TypeScript` `React` `Node.js` `Express` `Tailwind CSS` `Vite` `Git` `GitHub` `npm` `PWA` `Service Workers` `localStorage` `GitHub Actions` `REST APIs` `API health endpoints` `Responsive design` `Reusable components` `Configuration-driven UI` `Debugging` `Deployment` `Whop Elements checkout` `Lead capture` `Event tracking` `Invoice workflows`
